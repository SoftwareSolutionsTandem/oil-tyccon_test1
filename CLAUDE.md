# Oil Tycoon — заметки для ассистента

- Общение с владельцем проекта — **на русском**. Код, команды и идентификаторы — на английском; комментарии в коде — на русском.
- Концепция: `docs/PROJECT.md`. Решения по дизайну: `docs/DESIGN.md`. Архитектура: `docs/ARCHITECTURE.md`. План: `docs/ROADMAP.md`. Обновляй их, когда меняются решения.

## Команды
- `npm run dev` — разработка; `npm test` — тесты; `npm run typecheck`; `npm run build`.
- `BALANCE_LOG=1 npm test` — отчёт бота о темпе прохождения целей. Запускай после любых изменений чисел в `src/core/config.ts`.

## Правила
- `src/core` — без DOM и без `Math.random()` в симуляции (только `Rng` из состояния), чтобы сохранялись детерминизм и тестируемость.
- Любое изменение `GameState` → поднять `SAVE_VERSION` и добавить миграцию в `src/core/save.ts`.
- Денежный инвариант (`tests/core.test.ts`, `expectBalanced`) не должен ломаться: каждая операция с деньгами учитывается в `totals`.
- Нефть лежит в хранилищах (`Building.stored`), `s.oil` — производная сумма: меняешь запасы — вызывай `syncOil`. Инвариант `добыто − продано = сумма хранилищ` проверяется в `tests/logistics.test.ts`.
- Логистика (`src/core/network.ts`) не должна зависеть от порядка зданий в массиве: решения — по состоянию, применение — одновременно.
- Сорт нефти: у месторождения (`map.grade`) и у хранилища (`Building.grade`); хранилище не смешивает сорта. Цены — только через `gradePrice`.
- Визуальную проверку делать через Playwright (`window.oilTycoon` даёт доступ к состоянию); демо-сцена — `?demo`.
- Графика: все объекты строятся из примитивов `ModelPainter` с общим светом `LIGHT` и `MATERIALS` — не вставлять сторонние картинки другого стиля. Правила и порядок добавления объекта — `docs/ART.md`.
- После изменений рендера проверять FPS и время кадра (`renderer.frameMs`), память — `renderer.memoryStats()`.
- `src/render/terrain.ts` (и всё, что он импортирует) выполняется также в Web Worker: без `document`/`window`; холсты — только через `createCanvas`.
- Окружение за картой (`environment.ts`) — только визуальное: не добавлять туда ничего, что выглядит как актив игрока или доступная земля.
