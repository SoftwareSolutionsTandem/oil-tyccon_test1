# Архитектура

## Выбор технологий

| Решение | Почему |
|---|---|
| **Браузер, TypeScript** | Игра доступна по ссылке на любом устройстве, без установки. Строгая типизация защищает экономическую логику от ошибок. |
| **Canvas 2D, процедурное запекание спрайтов** | Объекты собираются из 3D-примитивов с единым светом и материалами и запекаются в спрайты; земля — процедурная текстура. Для сцены такого масштаба WebGL не нужен; при росте можно перейти на PixiJS, не трогая ядро. Подробно — [ART.md](ART.md). |
| **Чистый DOM для интерфейса** | Интерфейс — панели и кнопки; фреймворк дал бы зависимость без выигрыша на этом этапе. |
| **Vite** | Быстрая разработка и сборка статического сайта. |
| **Vitest** | Тесты ядра и автоматическая проверка баланса. |

### Принципы

- **Ядро не знает о рендере.** Всё состояние — один JSON-сериализуемый объект `GameState`. Это даёт сохранения, офлайн-прогресс и тесты бесплатно.
- **Фиксированный шаг симуляции** (0,1 с) независимо от FPS; скорость игры (×1/×2/×4) меняет количество шагов, а не их длину.
- **Детерминизм.** ГСЧ (mulberry32) хранит состояние в `GameState.rng`, поэтому одинаковые действия дают одинаковый результат — удобно для тестов и отладки.
- **Офлайн-прогресс** — та же функция `tick` с шагом 1 с, до 4 часов. Используется при загрузке и при возврате во вкладку.
- **Все числа баланса — в config.ts**, чтобы настройку можно было делать без поиска по коду.
- **Нефть хранится по месту** (`Building.stored` у конторы и резервуаров); `GameState.oil` — производная сумма, после любого изменения запасов вызывается `syncOil`.
- **Сеть выводится из состояния и кешируется.** `getNetwork` пересчитывает компоненты и маршруты только при изменении подписи (здания + трубы). Результаты потока последнего тика (`lastFlow`) — для интерфейса, в сохранение не входят.

## Отладка

Демо-сцена с готовым предприятием: `http://localhost:5173/?demo` (не трогает сохранение).


В консоли браузера доступен `window.oilTycoon` (`game`, `camera`, `renderer`, `core`), например:
`oilTycoon.game.state.cash += 1e5`.
