# Архитектура

## Выбор технологий

| Решение | Почему |
|---|---|
| **Браузер, TypeScript** | Игра доступна по ссылке на любом устройстве, без установки. Строгая типизация защищает экономическую логику от ошибок. |
| **Canvas 2D, процедурное запекание спрайтов** | Объекты собираются из 3D-примитивов с единым светом и материалами и запекаются в спрайты; земля — процедурная текстура. Для сцены такого масштаба WebGL не нужен; при росте можно перейти на PixiJS, не трогая ядро. Подробно — [ART.md](ART.md). |
| **Чистый DOM для интерфейса** | Интерфейс — панели и кнопки; фреймворк дал бы зависимость без выигрыша на этом этапе. |
| **Vite** | Быстрая разработка и сборка статического сайта. |
| **Vitest** | Тесты ядра и автоматическая проверка баланса. |

## Слои

```

  core/        Чистая симуляция: без DOM, детерминированная, сериализуемая
    config.ts      все числа баланса
    types.ts       GameState и сущности
    state.ts       новая игра, генерация карты
    sim.ts         tick(): рынок → логистика (отгрузка терминалов, продажа продуктов НПЗ, добыча и забор по сети) → содержание → статистика → цели; офлайн
    network.ts     сеть трубопроводов: компоненты, маршруты до хранилищ (кеш по подписи топологии), поток за тик
                   с обходами насыщенных труб и сортами нефти; НПЗ — клиент в общей очереди с терминалами
                   (refineryPlan: заявка с проверкой места на складах продуктов до забора)
    connect.ts     подключение с учётом загрузки сети: варианты маршрутов с расчётным потоком (пробный расчёт на копии)
    actions.ts     действия игрока (строить, улучшать, сносить, продавать, покупать землю, прокладывать трубы)
    economy.ts     формулы (стоимости, мощности, ёмкость, статистика); цены нефтепродуктов и маржа НПЗ —
                   детерминированные функции времени и зерна, без ГСЧ
    objectives.ts  цепочка целей (открывают здания: s.unlocked, проверка в canBuild)
    world.ts       участки земли (владение, соседство), разведка: уровень участка и оценка запасов в диапазоне
    rng.ts         детерминированный ГСЧ (mulberry32) с состоянием в GameState.rng
    save.ts        сохранение/загрузка с проверкой и миграцией версий
  render/      Рендер (только читает состояние), см. docs/ART.md
    model.ts       мини-3D: проекция, свет, материалы, примитивы, запекание спрайтов
    models.ts      модели объектов (качалка, резервуар, терминал, НПЗ, бензовоз, контора, декор)
    sprites.ts     библиотека запечённых спрайтов с кешем
    terrain.ts     процедурная текстура земли, пятна нефти, материалы площадок
    ground.ts      наземная инфраструктура: площадки, трубы по клеткам (из map.pipes), дороги в обход зданий (визуальные)
    particles.ts   частицы: пыль, выхлоп (пул на типизированных массивах)
    daylight.ts    время суток: цвет кадра, сила теней, ночное освещение
    environment.ts большой мир вокруг карты: степь, дальняя панорама, дымка, ориентиры
    mipmap.ts      уменьшенные копии холстов для отдалённой камеры
    terrainSource.ts, terrain.worker.ts  генерация текстуры земли в Web Worker
    renderer.ts    слои кадра, кеш земли по ячейкам, тени, сортировка по глубине, анимации, свет
  demo.ts      демо-сцена (?demo) для визуальной проверки
  ui/          HUD на DOM
  game.ts      связывает ядро, рендер и интерфейс; обратная связь на действия
  main.ts      игровой цикл, ввод, автосохранение, фоновый режим
tests/         тесты ядра + бот для проверки баланса
    core.test.ts             новая игра, стройка, экономика, цели, детерминизм, сохранения, офлайн, денежный инвариант
    logistics.test.ts        сеть труб: сохранность нефти, пропускная способность, обходы, порядок зданий, миграция v1
    quality.test.ts          сорта нефти: цены, хранилища одного сорта, миграция v2
    survey.test.ts           разведка: уровни, точность оценок, миграция v3
    refinery.test.ts         инварианты и сценарии НПЗ (фильтры, маржа, смеси, склады, конкуренция, миграция v4)
    unlock.test.ts           открытие зданий целями: canBuild до и после награды
    bot.ts                   «жадный» бот для баланса (трубы, узкие места, НПЗ)
    bot-refinery.test.ts     правила бота для НПЗ
```

### Принципы

- **Ядро не знает о рендере.** Всё состояние — один JSON-сериализуемый объект `GameState`. Это даёт сохранения, офлайн-прогресс и тесты бесплатно.
- **Фиксированный шаг симуляции** (0,1 с) независимо от FPS; скорость игры (×1/×2/×4) меняет количество шагов, а не их длину.
- **Детерминизм.** ГСЧ (mulberry32) хранит состояние в `GameState.rng`, поэтому одинаковые действия дают одинаковый результат — удобно для тестов и отладки.
- **Офлайн-прогресс** — та же функция `tick` с шагом 1 с, до 4 часов. Используется при загрузке и при возврате во вкладку.
- **Все числа баланса — в config.ts**, чтобы настройку можно было делать без поиска по коду.
- **Нефть хранится по месту** (`Building.stored` у конторы и резервуаров); `GameState.oil` — производная сумма, после любого изменения запасов вызывается `syncOil`.
- **Сеть выводится из состояния и кешируется.** `getNetwork` пересчитывает компоненты и маршруты только при изменении подписи (здания + трубы). Результаты потока последнего тика (`lastFlow`) — для интерфейса, в сохранение не входят.

## Отладка

Демо-сцена с готовым предприятием: `http://localhost:5173/?demo` (не трогает сохранение).


В консоли браузера доступен `window.oilTycoon` (`game`, `camera`, `renderer`, `core`), например:
`oilTycoon.game.state.cash += 1e5`.
