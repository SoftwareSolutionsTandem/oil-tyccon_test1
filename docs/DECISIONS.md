Принятые решения по дизайну и процессу. Решения В1–В12 и П1–П2 принял ведущий чат по поручению владельца проекта. Новые решения добавляются в конец таблицы своей вехи; отменённое
решение не удаляется, а получает статус «Отменено» со ссылкой на заменившее.

Даты: «записано» — дата внесения в журнал; дату принятия указываю, только если она известна.
