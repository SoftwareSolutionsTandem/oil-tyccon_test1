# Oil Tycoon

Изометрическая экономическая стратегия: от одной скважины до нефтяной империи.
Игра работает в браузере, без установки.

## Запуск

```bash
npm install
npm run dev        # режим разработки, http://localhost:5173
npm test           # тесты симуляции и баланса
npm run build      # проверка типов + сборка в dist/
```

Собранную папку `dist/` можно выложить на любой статический хостинг (пути относительные).

## Как играть

- **Станок-качалка (1)** — ставится на тёмное пятно месторождения, добывает нефть. Запасы истощаются, добыча падает.
- **Резервуар (2)** — увеличивает склад. Когда склад полон, качалки простаивают, но содержание идёт.
- **Наливной терминал (3)** — продаёт нефть сам и по полной цене; можно задать минимальную цену продажи.
- **Продать (S)** — ручная продажа перекупщику со скидкой 20%.
- **Земля** — щёлкните по затемнённому соседнему участку, чтобы увидеть запасы и купить его.

Управление камерой: перетаскивание мышью или стрелки, колесо — масштаб. Пробел — пауза, Esc — отмена.
Игра сохраняется автоматически и продолжает работать, пока вас нет (до 4 часов).
